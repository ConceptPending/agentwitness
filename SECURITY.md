# Security policy

The authoritative description of what an agentwitness bundle does and
does not prove is [`THREAT_MODEL.md`](./THREAT_MODEL.md).

agentwitness v0.1.x is the first publicly released line. There is no
formal coordinated-disclosure window yet; we aim to respond to security
reports within five business days.

To report a suspected security issue, email <nick@nickw.info>. Please
do not file a public issue for security-sensitive matters.
